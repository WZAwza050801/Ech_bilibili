# 管线二实施与验收

输入 B 站单集（支持 `?p=N`）或本地视频，输出内容消化后的中文讲义。
首次实现选择多模态模型直接读帧；Pix2Text 留作以后可选后端，不增加双套依赖。

1. 证据底座：沿用管线一 playurl / 浏览器请求头 / 本地 Whisper 参数。
   独立运行目录；课程独立热词表；原始转写不可覆盖；下载临时文件原子落盘。
2. 画面：scene + uniform + max-min 选点；记录 requested_t 与解码 PTS actual_t。
   保守重复检测保留每次出现的时间；不因“像人像”而自动丢帧。
3. 写作：10 分钟时间窗再按帧数细分；map 输出定义/定理/推导/例题和证据 ID。
   reduce 只组织全部知识块，不能重写公式或静默删块；公式再读原帧核验。
4. 输出：结构化 JSON → 受限 LaTeX 模板 → XeLaTeX 两遍 → PDF。
   输出术语冲突、疑点、公式检查与证据索引，按“课程讲义-标题-日期-视频ID”归档。

验收：
- 时间边界、缓存参数变化、非法证据引用、公式与 LaTeX 安全边界有测试。
- 合成课程视频通过真实 ffmpeg 抽帧与 XeLaTeX 编译；假模型仅测试控制流。
- 真实模型可用性单独验证；真实 B 站课程验收等待用户提供链接。
- 原管线一不修改；仅提交新增管线代码与必要文档，不提交密钥、视频或课程产物。

限制：编译成功不等于数学正确；模型视觉复查不是独立数学证明。
均匀间隔/帧预算可能漏掉短暂板书，质量报告必须披露，支持调密重跑。
